# 测试 Mania Stage Bottom BPM 特效

## 快速测试步骤

### 1. 编译项目

```bash
cd osu.Desktop
dotnet build
```

### 2. 准备测试皮肤

在你的 osu! 皮肤文件夹中创建测试图片：

#### 位置
`C:\Users\[你的用户名]\AppData\Local\osu\Skins\[你的皮肤名称]\`

#### 创建测试图片

**方法 A - 简单纯色测试图**
创建一个纯白色的 PNG 图片：
- 文件名：`mania-stage-bottom-fx@2x.png`
- 尺寸：建议 800x200 像素（或与你的 stage-bottom 相同）
- 内容：纯白色，带有 50% 透明度
- 格式：PNG-24（支持透明通道）

**方法 B - 发光效果测试图**
创建一个渐变发光效果：
- 文件名：`mania-stage-bottom-fx@2x.png`
- 内容：从中心向外的白色放射渐变
- 边缘：完全透明
- 中心：80% 不透明度的白色

**方法 C - 使用现有的 stage-bottom**
如果你已有 `mania-stage-bottom@2x.png`：
1. 复制它
2. 重命名为 `mania-stage-bottom-fx@2x.png`
3. 在图片编辑器中增加亮度和对比度
4. 添加外发光效果
5. 降低整体透明度到 70%

### 3. 运行游戏测试

```bash
cd osu.Desktop\bin\Release\net8.0
.\osu.exe
```

或者如果是 Debug 模式：
```bash
cd osu.Desktop\bin\Debug\net8.0
.\osu.exe
```

### 4. 验证效果

1. 进入游戏
2. 选择你准备好的皮肤
3. 进入一个 mania 谱面
4. 开始游玩或观看回放

**预期效果：**
- ✅ 底部会有一个特效层
- ✅ 特效会随着音乐的每一拍闪烁
- ✅ 闪烁频率自动匹配 BPM
- ✅ 快速淡入（40ms），然后缓慢淡出
- ✅ 变速段落会自动调整闪烁速度

### 5. 调试信息

如果特效没有显示，检查：

1. **文件名是否正确**
   - 必须是 `mania-stage-bottom-fx@2x.png` 或 `mania-stage-bottom-fx.png`
   - 注意全部小写，连字符不要写错

2. **文件路径是否正确**
   - 放在当前皮肤文件夹根目录
   - 不要放在子文件夹中

3. **图片格式是否正确**
   - 必须是 PNG 格式
   - 建议使用 PNG-24 或 PNG-32（支持透明通道）

4. **查看控制台输出**
   - 运行游戏时查看控制台是否有相关日志

## 高级测试

### 测试不同 BPM

创建或下载不同 BPM 的谱面进行测试：
- **慢歌** (BPM 80-120)：闪烁较慢，效果更明显
- **中速** (BPM 120-180)：标准效果
- **快歌** (BPM 180-240)：快速闪烁
- **超高速** (BPM 240+)：自动加倍节拍长度，避免过快

### 测试变速段落

找一个包含变速（BPM changes）的谱面，观察特效是否能够：
- ✅ 实时切换到新的 BPM
- ✅ 平滑过渡
- ✅ 始终与节拍同步

### 测试滚动方向

在游戏设置中切换滚动方向：
- **向下滚动**（默认）：特效应该在底部
- **向上滚动**：特效应该跟随到顶部

### 测试多列布局

测试不同的按键数量：
- 4K
- 5K
- 6K
- 7K
- 8K
- 9K

确保特效在所有布局下都能正确显示。

## 创建美观的特效图片建议

### Photoshop / GIMP 制作步骤

1. **创建新图片**
   - 尺寸：1600x400 像素（@2x）
   - 背景：透明

2. **添加基础形状**
   - 绘制一个水平矩形或渐变
   - 或者导入你的 stage-bottom 图片作为参考

3. **添加发光效果**
   - 应用外发光（Outer Glow）
   - 颜色：白色或你喜欢的颜色
   - 扩散：20-30 像素
   - 不透明度：80%

4. **添加内发光（可选）**
   - 应用内发光（Inner Glow）
   - 颜色：浅色
   - 混合模式：叠加（Overlay）或屏幕（Screen）

5. **调整整体透明度**
   - 建议 60-80%
   - 这样闪烁效果会更自然

6. **保存**
   - 格式：PNG-24
   - 确保保留透明通道
   - 文件名：`mania-stage-bottom-fx@2x.png`

### 效果参考

**简约风格：**

**科技风格：**

## 故障排查

### 问题：特效不显示

**可能原因：**
1. 文件名错误 → 检查拼写和大小写
2. 文件格式错误 → 确保是 PNG 格式
3. 图片完全透明 → 检查图片内容
4. 皮肤未正确选择 → 重新选择皮肤

### 问题：特效显示但不闪烁

**可能原因：**
1. 图片已经是完全不透明的白色 → 调整图片透明度
2. BeatSyncedContainer 未正确初始化 → 检查代码
3. 音乐未播放 → 确保谱面正在运行

### 问题：闪烁频率不对

**可能原因：**
1. 谱面 timing 不正确 → 检查谱面设置
2. BPM 检测错误 → 查看控制台日志

### 问题：性能下降

**可能原因：**
1. 图片文件太大 → 优化图片大小（推荐 < 1MB）
2. 使用了动画序列 → 减少帧数
3. 多个特效叠加 → 简化设计
